  <action>
Add `resolve_tags_with_assets()` as a new async function in tag_resolver.py. This is a superset of resolve_tags() -- it resolves tag text AND populates ResolvedAssetRef objects with structured metadata from the library entities.

Implementation:

1. Signature: `async def resolve_tags_with_assets(prompt: str, production_bible_id: uuid.UUID, session: AsyncSession) -> ResolvedPrompt`

2. **Batch pre-load all bindings** for the bible (3 queries total, not N*3 per the Research anti-pattern guidance):
   ```python
   # Load all CastBindings for this bible
   cast_result = await session.execute(
       select(CastBinding).where(CastBinding.production_bible_id == production_bible_id)
   )
   cast_bindings = cast_result.scalars().all()
   cast_by_tag = {b.tag.upper(): b for b in cast_bindings}

   # Same for PropBinding and SetBinding
   prop_result = await session.execute(...)
   prop_by_tag = {b.tag.upper(): b for b in prop_bindings}
   set_result = await session.execute(...)
   set_by_tag = {b.tag.upper(): b for b in set_bindings}
   ```

3. **Batch-load all referenced entities and their refs** to avoid N+1:
   - Collect all actor_ids from cast_bindings, fetch Actors and ActorRefs in bulk.
   - Collect all library_prop_ids, fetch LibraryProps and LibraryPropRefs in bulk.
   - Collect all library_set_ids, fetch LibrarySets and LibrarySetRefs in bulk.
   - Build lookup dicts: actors_by_id, actor_refs_by_actor_id (list), props_by_id, prop_refs_by_prop_id, sets_by_id, set_refs_by_set_id.

4. **Resolve [TYPE:TAG] matches first** (same text substitution as resolve_tags), building ResolvedAssetRef for each. Track resolved tag names.

5. **Resolve @tag matches second** using the pre-loaded dicts:
   - `upper_tag = tag_name.upper()`
   - Check cast_by_tag first, then prop_by_tag, then set_by_tag.
   - Skip if upper_tag already in resolved set.
   - On match: substitute text, build ResolvedAssetRef from the entity data, add to asset_refs list, add to resolved set.
   - On no match: leave @tag as-is, add to unresolved_tags.

6. **Building ResolvedAssetRef** for each resolved tag:
   - CHARACTER: tag=upper_tag, asset_type="CHARACTER", display_name=binding.character_name, text_description=actor.base_appearance_prompt or "", reference_image_urls=[r.image_url for r in actor_refs_by_actor_id.get(binding.actor_id, [])], lora_url=None, wardrobe_override=binding.wardrobe_override, lighting_notes=None
   - SET: tag=upper_tag, asset_type="SET", display_name=binding.production_name or lib_set.name, text_description=lib_set.reverse_prompt or "", reference_image_urls=[r.image_url for r in set_refs_by_set_id.get(binding.library_set_id, [])], lora_url=None, wardrobe_override=None, lighting_notes=binding.lighting_override or lib_set.lighting_notes
   - PROP: tag=upper_tag, asset_type="PROP", display_name=binding.production_name or lib_prop.name, text_description=lib_prop.appearance_prompt or "", reference_image_urls=[r.image_url for r in prop_refs_by_prop_id.get(binding.library_prop_id, [])], lora_url=None, wardrobe_override=None, lighting_notes=None

7. Null-check entities: if actor/set/prop is None (deleted), treat as unresolved per Research Pitfall 4.

8. Log warning when @tag matches multiple binding types (first match wins but log the collision).

Return ResolvedPrompt with text, asset_refs, character_refs, set_context, unresolved_tags all populated.
