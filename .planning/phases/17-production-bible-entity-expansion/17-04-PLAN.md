**In `frontend/src/api/client.ts`**, add API functions following the existing pattern (using the `API_BASE` and fetch wrapper):

**Character functions:**
- `listCharacters(bibleId: string): Promise<CharacterResponse[]>` — GET `/api/production-bibles/${bibleId}/characters`
- `createCharacter(bibleId: string, data: { name: string; role: string; description?: string; arc?: string; base_appearance?: string; prompt_tags?: string[] }): Promise<CharacterResponse>` — POST
- `getCharacter(characterId: string): Promise<CharacterResponse>` — GET `/api/characters/${characterId}`
- `updateCharacter(characterId: string, data: Partial<...>): Promise<CharacterResponse>` — PUT
- `deleteCharacter(characterId: string): Promise<void>` — DELETE
- `createWardrobe(characterId: string, data: { label: string; scene_context?: string; prompt_descriptor?: string; is_default?: boolean }): Promise<WardrobeResponse>` — POST `/api/characters/${characterId}/wardrobes`
- `updateWardrobe(wardrobeId: string, data: Partial<...>): Promise<WardrobeResponse>` — PUT `/api/wardrobes/${wardrobeId}`
- `deleteWardrobe(wardrobeId: string): Promise<void>` — DELETE
- `upsertVoiceProfile(characterId: string, data: { voice_id?: string; adapter_type?: string; style_notes?: string }): Promise<VoiceProfileResponse>` — PUT `/api/characters/${characterId}/voice-profile`
- `deleteVoiceProfile(characterId: string): Promise<void>` — DELETE

**Set/Prop functions:**
- `listSets(bibleId: string): Promise<SetResponse[]>` — GET `/api/production-bibles/${bibleId}/sets`
- `createSet(bibleId: string, data: { name: string; style_tags?: string[]; lighting_notes?: string; prompt_tags?: string[] }): Promise<SetResponse>` — POST
- `getSet(setId: string): Promise<SetResponse>` — GET `/api/sets/${setId}`
- `updateSet(setId: string, data: Partial<...>): Promise<SetResponse>` — PUT
- `deleteSet(setId: string): Promise<void>` — DELETE
- `uploadSetReference(setId: string, file: File): Promise<SetResponse>` — POST multipart to `/api/sets/${setId}/upload-reference`
- `upsertSonicIdentity(setId: string, data: { ambience_description?: string; generation_prompt?: string }): Promise<SonicIdentityResponse>` — PUT `/api/sets/${setId}/sonic-identity`
- `deleteSonicIdentity(setId: string): Promise<void>` — DELETE
- `listProps(bibleId: string): Promise<PropResponse[]>` — GET `/api/production-bibles/${bibleId}/props`
- `createProp(bibleId: string, data: { name: string; description?: string; associated_characters?: string[]; prompt_tags?: string[] }): Promise<PropResponse>` — POST
- `updateProp(propId: string, data: Partial<...>): Promise<PropResponse>` — PUT `/api/props/${propId}`
- `deleteProp(propId: string): Promise<void>` — DELETE

**Sound functions:**
- `listScoreThemes(bibleId: string): Promise<ScoreThemeResponse[]>` — GET `/api/production-bibles/${bibleId}/score-themes`
- `createScoreTheme(bibleId: string, data: { name: string; mood_descriptors?: string[]; tempo_notes?: string; usage_notes?: string; generation_prompt?: string }): Promise<ScoreThemeResponse>` — POST
- `updateScoreTheme(themeId: string, data: Partial<...>): Promise<ScoreThemeResponse>` — PUT `/api/score-themes/${themeId}`
- `deleteScoreTheme(themeId: string): Promise<void>` — DELETE
- `listSFXItems(bibleId: string, category?: string): Promise<SFXItemResponse[]>` — GET `/api/production-bibles/${bibleId}/sfx` (append `?category=${category}` if provided)
- `createSFXItem(bibleId: string, data: { name: string; category: string; generation_prompt?: string; tags?: string[] }): Promise<SFXItemResponse>` — POST
- `updateSFXItem(sfxId: string, data: Partial<...>): Promise<SFXItemResponse>` — PUT `/api/sfx/${sfxId}`
- `deleteSFXItem(sfxId: string): Promise<void>` — DELETE

**Migration function:**
- `migrateEntities(bibleId: string): Promise<{ characters_created: number; sets_created: number }>` — POST `/api/production-bibles/${bibleId}/migrate-entities`

Use `import type { CharacterResponse, ... }` for type-only imports per project convention.
