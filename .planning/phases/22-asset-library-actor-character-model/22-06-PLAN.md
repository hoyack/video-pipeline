  <name>Task 1: Create promote-to-library endpoints for Characters, Sets, Props</name>
  <files>backend/vidpipe/api/asset_library.py</files>
  <action>
Add promote-to-library endpoints to asset_library.py. These copy data from bible-scoped entities to library entities and create auto-bindings back.

**POST /api/characters/{character_id}/promote-to-library:**
1. Load Character by ID. Return 404 if not found.
2. If character.promoted_to_actor_id is not None, return 409 "Already promoted to Actor {id}".
3. Create Actor from character data:
   - name = character.name
   - description = character.description
   - base_appearance_prompt = character.base_appearance (existing column)
   - prompt_tags = character.prompt_tags
4. Copy Wardrobe items: for each Wardrobe with character_id, create ActorWardrobePreset:
   - label = wardrobe.label
   - description = wardrobe.prompt_descriptor
   - reference_images = wardrobe.reference_images
5. Copy VoiceProfile: if VoiceProfile exists for character, create ActorVoiceProfile:
   - voice_id = voice_profile.voice_id
   - adapter_type = voice_profile.adapter_type
   - style_notes = voice_profile.style_notes
   - sample_url = voice_profile.sample_audio_url
6. Copy actor refs from character's actor_refs (the reference images stored on the character):
   - Query for any existing reference images associated with this character
   - Create ActorRef entries for each
7. Create CastBinding:
   - production_bible_id = character.production_bible_id
   - actor_id = new_actor.id
   - tag = derive from character.name (uppercase, replace spaces with underscore, strip non-alphanumeric)
   - character_name = character.name
   - role = character.role (map existing role values to LEAD/SUPPORTING/EXTRA/NARRATOR)
   - character_description = character.description
   - character_arc = character.arc
   - voice_profile_id = new_actor_voice_profile.id (if created)
8. Set character.promoted_to_actor_id = new_actor.id
9. Commit and return { actor_id, cast_binding_id, tag }.

**POST /api/sets/{set_id}/promote-to-library:**
1. Load Set. Check promoted_to_library_set_id (409 if already promoted).
2. Create LibrarySet:
   - name = set.name, description = set.description, reverse_prompt = set.reverse_prompt
   - style_tags = set.style_tags, prompt_tags = set.prompt_tags, lighting_notes = set.lighting_notes
3. If set has reference_image_url, create LibrarySetRef with that URL.
4. If SonicIdentity exists for this set, create LibrarySonicIdentity:
   - ambience_description, reference_audio_url, generation_prompt
5. Create SetBinding:
   - production_bible_id = set.production_bible_id
   - library_set_id = new_library_set.id
   - tag = derive from set.name
   - production_name = set.name
6. Set set.promoted_to_library_set_id = new_library_set.id
7. Commit and return.

**POST /api/props/{prop_id}/promote-to-library:**
1. Load Prop. Check promoted_to_library_prop_id.
2. Create LibraryProp:
   - name = prop.name, description = prop.description
   - appearance_prompt = prop.description (reuse description as appearance prompt)
   - prompt_tags = prop.prompt_tags
3. If prop has reference_image_url, create LibraryPropRef.
4. Create PropBinding:
   - production_bible_id = prop.production_bible_id
   - library_prop_id = new_library_prop.id
   - tag = derive from prop.name
   - production_name = prop.name
5. Set prop.promoted_to_library_prop_id = new_library_prop.id
6. Commit and return.

**POST /api/score-themes/{id}/promote-to-library** and **POST /api/sfx-items/{id}/promote-to-library:**
- Create SoundAsset with category=SCORE_THEME or category matching SFX/AMBIENCE/etc.
- Copy name, description, reference_audio_url -> audio_url, generation_prompt, tags
- Create SoundBinding
- Set promoted_to_sound_asset_id

**Helper function** `_derive_tag(name: str) -> str`:
```python
import re
def _derive_tag(name: str) -> str:
    """Derive a tag from an entity name: 'King Aldric' -> 'KING_ALDRIC'"""
    cleaned = re.sub(r'[^a-zA-Z0-9\s]', '', name)
    return cleaned.strip().upper().replace(' ', '_')[:50]
```

All promote endpoints should be idempotent: check promoted_to column first, return 409 with existing library ID if already promoted.

- If tags found but no matching bindings, leave tags in place and add to unresolved_tags list (log warning, don't fail)

**In tag_resolver.py:**
- Add a convenience function `has_tags(text: str) -> bool` that returns True if TAG_PATTERN finds any matches
- Ensure resolve_tags handles None/empty prompt gracefully (return unchanged)
- Add logging for unresolved tags at WARNING level

The key integration point is in the pipeline code that prepares prompts for keyframe and video generation. Look for where `scene.start_frame_prompt` etc. are read and passed to the generation APIs. Insert tag resolution there.
