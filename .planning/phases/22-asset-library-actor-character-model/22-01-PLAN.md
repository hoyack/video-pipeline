Add the following ORM model classes AFTER the existing SFXItem class in models.py. Follow the exact same patterns as existing Phase 17 models (Mapped[] annotations, uuid.UUID PKs, server_default for booleans, JSON for arrays).

**Actor (standalone entity):**
- `actors` table: id (UUID PK), name (Text), description (Text nullable), base_appearance_prompt (Text nullable), prompt_tags (JSON nullable), created_at (server_default=func.now()), updated_at (server_default=func.now(), onupdate=func.now())

**ActorRef (1:N sub-entity of Actor):**
- `actor_refs` table: id (UUID PK), actor_id (FK actors.id, indexed), image_url (String(500)), label (String(50) nullable -- front/profile/3-4), is_primary (Boolean, default=False, server_default=text("false")), created_at

**ActorVoiceProfile (1:N sub-entity of Actor):**
- `actor_voice_profiles` table: id (UUID PK), actor_id (FK actors.id, indexed), voice_id (String(200) nullable), adapter_type (String(30) nullable -- ELEVENLABS/BARK/XTTS/CUSTOM), style_notes (Text nullable), sample_url (String(500) nullable), created_at
- Separate from existing voice_profiles table (which has character_id FK) per Research pitfall 1

**ActorWardrobePreset (1:N sub-entity of Actor):**
- `actor_wardrobe_presets` table: id (UUID PK), actor_id (FK actors.id, indexed), label (String(200)), description (Text nullable), reference_images (JSON nullable -- list of image URLs), created_at
- Separate from existing wardrobes table per Research pitfall 2

**LibrarySet (standalone entity):**
- `library_sets` table: id (UUID PK), name (Text), description (Text nullable), reverse_prompt (Text nullable), style_tags (JSON nullable), prompt_tags (JSON nullable), lighting_notes (Text nullable), created_at, updated_at
- Named `library_sets` to avoid collision with existing `sets` table per Research pitfall 2

**LibrarySetRef (1:N sub-entity of LibrarySet):**
- `library_set_refs` table: id (UUID PK), library_set_id (FK library_sets.id, indexed), image_url (String(500)), label (String(100) nullable), is_primary (Boolean default=False), created_at

**LibrarySonicIdentity (1:1 sub-entity of LibrarySet):**
- `library_sonic_identities` table: id (UUID PK), library_set_id (FK library_sets.id, unique, indexed), ambience_description (Text nullable), reference_audio_url (String(500) nullable), generation_prompt (Text nullable), created_at

**LibraryProp (standalone entity):**
- `library_props` table: id (UUID PK), name (Text), description (Text nullable), appearance_prompt (Text nullable), prompt_tags (JSON nullable), created_at, updated_at

**LibraryPropRef (1:N sub-entity of LibraryProp):**
- `library_prop_refs` table: id (UUID PK), library_prop_id (FK library_props.id, indexed), image_url (String(500)), label (String(100) nullable), is_primary (Boolean default=False), created_at

**SoundAsset (standalone entity -- unified per Research recommendation):**
- `sound_assets` table: id (UUID PK), name (Text), category (String(30) -- SCORE_THEME/SFX/AMBIENCE/FOLEY/UI), subcategory (String(100) nullable), description (Text nullable), audio_url (String(500) nullable), generation_prompt (Text nullable), tags (JSON nullable), created_at, updated_at

**CastBinding (Actor -> Production Bible):**
- `cast_bindings` table: id (UUID PK), production_bible_id (FK production_bibles.id, indexed), actor_id (FK actors.id, indexed), tag (String(100) -- unique per bible, e.g. KING_ALDRIC), character_name (Text), character_description (Text nullable), character_arc (Text nullable), role (String(30) -- LEAD/SUPPORTING/EXTRA/NARRATOR), wardrobe_override (JSON nullable), voice_profile_id (FK actor_voice_profiles.id nullable), behavioral_notes (Text nullable), prompt_tags (JSON nullable), created_at, updated_at
- UniqueConstraint on (production_bible_id, actor_id) named uq_cast_bible_actor
- UniqueConstraint on (production_bible_id, tag) named uq_cast_bible_tag
- Per Research open question 4: dedicated `tag` column for tag resolution, plus `prompt_tags` for additional injection

**SetBinding (LibrarySet -> Production Bible):**
- `set_bindings` table: id (UUID PK), production_bible_id (FK production_bibles.id, indexed), library_set_id (FK library_sets.id, indexed), tag (String(100), unique per bible), production_name (Text nullable), lighting_override (Text nullable), sonic_override (Text nullable), prompt_tags (JSON nullable), created_at, updated_at
- UniqueConstraint on (production_bible_id, library_set_id)
- UniqueConstraint on (production_bible_id, tag)

**PropBinding (LibraryProp -> Production Bible):**
- `prop_bindings` table: id (UUID PK), production_bible_id (FK production_bibles.id, indexed), library_prop_id (FK library_props.id, indexed), tag (String(100), unique per bible), production_name (Text nullable), notes (Text nullable), prompt_tags (JSON nullable), created_at, updated_at
- UniqueConstraint on (production_bible_id, library_prop_id)
- UniqueConstraint on (production_bible_id, tag)

**SoundBinding (SoundAsset -> Production Bible):**
- `sound_bindings` table: id (UUID PK), production_bible_id (FK production_bibles.id, indexed), sound_asset_id (FK sound_assets.id, indexed), tag (String(100) nullable), usage_notes (Text nullable), prompt_tags (JSON nullable), created_at, updated_at
- UniqueConstraint on (production_bible_id, sound_asset_id)

Use `from sqlalchemy import UniqueConstraint` (already imported if not, add to imports). Follow the existing import patterns at the top of models.py.
