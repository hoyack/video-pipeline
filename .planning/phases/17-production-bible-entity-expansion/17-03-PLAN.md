```python
@character_router.post("/production-bibles/{production_bible_id}/migrate-entities", status_code=200)
async def migrate_entities(production_bible_id: str):
    from vidpipe.services.production_bible_entity_service import migrate_all_assets
    async with async_session() as session:
        bible = await session.get(ProductionBible, uuid.UUID(production_bible_id))
        if not bible:
            raise HTTPException(404, "Production Bible not found")
        result = await migrate_all_assets(session, bible.id)
        await session.commit()
        return result
```

This satisfies PBEX-06 (CHARACTER migration) and PBEX-12 (ENVIRONMENT migration). The migration is idempotent (checks for existing entities by name before creating).

Import notes:
- `from sqlalchemy import select` for queries
- `from vidpipe.db.models import Asset, Character, Set` for ORM access
- Use `session.execute(select(...).where(...))` pattern
