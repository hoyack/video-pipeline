<objective>
Fix the `load_bible_context` indirect lookup so Production Bible context is available to the Screenwriter even before any Scenes exist, add production_bible_id propagation, update API responses, and remove the dead sound_router guard.

Purpose: The "Bible -> Screenplay -> Generate Full" flow silently loses all bible context because `load_bible_context` queries Scene.production_bible_id which returns nothing when no scenes exist yet. This breaks SCRN-10 (bible context injection into Screenwriter prompts).

Output: Working `load_bible_context` using Production.production_bible_id direct FK, updated API schema, auto-propagation to scenes, clean sound_router import.
</objective>

       session: AsyncSession,

           select(Production.production_bible_id)
