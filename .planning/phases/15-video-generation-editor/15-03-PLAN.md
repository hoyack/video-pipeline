**Editor mode logic:**
```typescript
function getEditorMode(): EditorMode {
  if (!projectId || !detail) return "drafting";
  const runningStatuses = new Set(["pending", "storyboarding", "keyframing", "video_gen", "stitching"]);
  if (runningStatuses.has(detail.status)) return "running";
  return "editing"; // draft, stopped, staged, failed, complete
}
```
NOTE: "draft" status maps to "editing" mode (user can edit before first generation).

**Key behaviors:**

1. **On mount with no projectId:** Show config bar expanded, empty scene placeholder grid (just the count), Generate button
2. **On mount with projectId:** Call `getProjectDetail(projectId)` to load existing project data, populate config from detail, show scenes

3. **Generate button click:**
   - If no projectId: call `createDraftProject({...config})`, get back `project_id`, set projectId, then immediately call `startGeneration(project_id, {run_through: ...})`
   - If projectId exists (editing/draft mode): call `startGeneration(projectId, {run_through: ...})` directly
   - Start polling

4. **Polling (during "running" mode):**
   - Use the existing `usePolling` hook pattern (check how ProgressView does it) or a simple `useEffect` with `setInterval`
   - Poll `getProjectDetail(projectId)` every 2 seconds
   - On each response, diff scenes against `prevScenesRef.current`:
     - For each scene, check if `has_start_keyframe`, `has_end_keyframe`, `has_clip` changed from false→true
     - If changed, add to `newAssetFlags` with a timestamp, then setTimeout(2000) to clear (brief green highlight)
   - Update `prevScenesRef.current` with new scene data
   - Stop polling when status is terminal (`complete`, `failed`, `stopped`, `staged`, `draft`)

5. **Pause button (during "running" mode):**
   - Call existing `POST /api/projects/{id}/stop` endpoint
   - Polling will pick up the "stopped" status and transition to editing mode

6. **Resume / Re-generate (during "editing" mode):**
   - Same as Generate button with existing projectId

7. **Scene grid:**
   - Render `SceneEditorCard` for each scene in `detail.scenes`
   - In drafting mode (no detail yet), render `sceneCount` placeholder cards with dashed borders (simple divs, not SceneEditorCard)
   - SceneEditorCard already handles: upload keyframes/clips, regen per-asset, text editing, empty slots, staleness
   - Pass `isGeneratingAssets` prop based on `scene.generation_status != null`
   - For newly-arrived assets (in `newAssetFlags`), add `ring-2 ring-green-400 transition-all` CSS class to the scene card

8. **Config bar auto-collapse:** When editorMode transitions to "running", auto-collapse if expanded. `useEffect(() => { if (editorMode === "running") setConfigExpanded(false); }, [editorMode])`

9. **Cost estimation:** Reuse `estimatePartialCost` from `frontend/src/lib/constants.ts` or wherever it's defined. Display estimated cost next to Generate button.
