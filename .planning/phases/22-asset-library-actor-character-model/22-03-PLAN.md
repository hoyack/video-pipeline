**tag_resolver.py** -- Create service module:
```python
import re
import uuid
from dataclasses import dataclass, field
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

TAG_PATTERN = re.compile(r'\[(CHAR|SET|PROP):([A-Z0-9_]+)\]')

@dataclass
class ResolvedPrompt:
    text: str
    character_refs: list = field(default_factory=list)  # list of {actor_id, ref_urls}
    set_context: list = field(default_factory=list)     # list of {set_id, lighting, style}
    unresolved_tags: list = field(default_factory=list)  # tags that didn't match

async def resolve_tags(prompt: str, production_bible_id: uuid.UUID, session: AsyncSession) -> ResolvedPrompt:
    """Resolve [CHAR:TAG], [SET:TAG], [PROP:TAG] to bound asset data."""
```

Implementation:
1. Find all tag matches in prompt via TAG_PATTERN.findall()
2. For CHAR tags: query CastBinding where production_bible_id=bible_id and tag=tag_name. If found, load Actor via actor_id, substitute tag in prompt with `{character_name} ({base_appearance_prompt})`, collect ActorRef image_urls into character_refs list.
3. For SET tags: query SetBinding where production_bible_id=bible_id and tag=tag_name. If found, load LibrarySet, substitute with `{production_name or set.name} ({set.reverse_prompt})`, collect lighting_override or set.lighting_notes into set_context.
4. For PROP tags: query PropBinding where production_bible_id=bible_id and tag=tag_name. If found, load LibraryProp, substitute with `{production_name or prop.name} ({prop.appearance_prompt})`.
5. Unmatched tags go to unresolved_tags list (no error, graceful).
6. Return ResolvedPrompt with resolved text, character_refs, set_context, unresolved_tags.
