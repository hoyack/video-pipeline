Create `backend/vidpipe/services/lora_trainer.py` with the following structure:

1. **TrainingJob dataclass:**
   ```python
   @dataclass
   class TrainingJob:
       job_id: str
       status: str  # QUEUED, TRAINING, COMPLETED, FAILED
       progress: Optional[float] = None  # 0.0-1.0
       weights_url: Optional[str] = None  # URL to download .safetensors
       error: Optional[str] = None
       logs: Optional[str] = None
   ```

2. **LoRATrainingBackend ABC:**
   ```python
   class LoRATrainingBackend(ABC):
       @abstractmethod
       async def dispatch(self, dataset_url: str, trigger_word: str, *, steps: int = 1000, lora_rank: int = 32, learning_rate: float = 0.0004) -> TrainingJob: ...
       @abstractmethod
       async def poll_status(self, job_id: str) -> TrainingJob: ...
       @abstractmethod
       async def get_result(self, job_id: str) -> bytes: ...
   ```

3. **ReplicateBackend implementation:**
   - `__init__(self, api_token: str, username: str = "vidpipe")` — creates `replicate.Client(api_token=api_token)`
   - `dispatch()` — wraps `self._client.trainings.create()` in `asyncio.to_thread()`. Uses model version `ostris/flux-dev-lora-trainer` (pick latest version hash from Replicate). Input: `input_images` (dataset URL), `trigger_word`, `steps`, `lora_rank`, `learning_rate`, `autocaption=False`, `resolution="512,768,1024"`. Destination: `{self._username}/vidpipe-lora-{trigger_word.lower()}`. Returns TrainingJob with status "QUEUED".
   - `poll_status()` — wraps `self._client.trainings.get(job_id)` in `asyncio.to_thread()`. Maps Replicate statuses: starting→QUEUED, processing→TRAINING, succeeded→COMPLETED, failed/canceled→FAILED. Extracts `weights` URL from `training.output` on success.
   - `get_result()` — downloads weights from `weights_url` using `httpx.AsyncClient` with 120s timeout. Returns raw bytes.

4. **Dataset preparation functions (module-level):**
   - `_resize_with_padding(image_bytes: bytes, target_size: int = 1024) -> bytes` — Uses `PIL.Image.open()`, `PIL.ImageOps.pad()` with `(target_size, target_size)`, white fill, saves as PNG.
   - `_generate_caption(adapter: LLMAdapter, image_bytes: bytes, trigger_word: str) -> str` — Uses existing LLM adapter `analyze_image()` with Pydantic schema `ImageCaption(caption: str)`. Prompt: describe appearance in detail, no names, start with trigger word. Temperature 0.3.
   - `async def prepare_dataset(actor_id: uuid.UUID, session: AsyncSession, vision_adapter: LLMAdapter, file_mgr: FileManager) -> tuple[bytes, str]` — Loads Actor + ActorRefs from DB. Builds trigger_word as `ACTOR_{actor.name.upper().replace(' ', '_')}`. For each ref: read_bytes via file_mgr, resize with padding, generate caption via VLM. Packages into a zipfile (in-memory BytesIO) with matching `{i:03d}.png` and `{i:03d}.txt` filenames. Returns (zip_bytes, trigger_word).

5. **Result storage function:**
   - `async def download_and_store_weights(weights_url: str, actor_id: str, storage: StorageBackend) -> str` — Downloads .safetensors from Replicate output URL via httpx.AsyncClient (120s timeout). Stores to S3/local at key `asset-library/actors/{actor_id}/lora/model.safetensors`. Returns the storage key.

6. **Imports:** Use `from abc import ABC, abstractmethod`, `from dataclasses import dataclass`, `asyncio`, `io`, `uuid`, `zipfile`, `logging`, `httpx`, `PIL.Image`, `PIL.ImageOps`, `pydantic.BaseModel`. Import `LLMAdapter` with TYPE_CHECKING guard to avoid circular imports. Import `FileManager` from `vidpipe.services.file_manager`, `StorageBackend` from `vidpipe.services.storage_backend`, `Actor`, `ActorRef` from `vidpipe.db.models`, `AsyncSession` from `sqlalchemy.ext.asyncio`, `select` from `sqlalchemy`.

**CRITICAL:** All replicate SDK calls MUST be wrapped in `asyncio.to_thread()` — the SDK is synchronous and will block the event loop otherwise.
