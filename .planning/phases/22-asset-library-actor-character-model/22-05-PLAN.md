**AssetPicker.tsx** -- Generic, reusable modal for browsing and selecting assets from the global library.

Props:
```typescript
interface AssetPickerProps {
  isOpen: boolean;
  onClose: () => void;
  assetType: "actor" | "set" | "prop" | "sound";
  onSelect: (asset: { id: string; name: string; primary_ref_url?: string | null }) => void;
  excludeIds?: string[];  // Already-bound asset IDs to exclude
}
```

Structure:
1. Modal overlay (fixed inset-0, bg-black/50, z-50) with centered panel (max-w-2xl, bg-gray-900, rounded-xl)
2. Header: "Select {AssetType}" title + close X button
3. Search input (debounced 300ms)
4. Grid of selectable cards (based on assetType):
   - For "actor": show ActorListItem cards with thumbnail, name, ref_count badge
   - For "set": LibrarySetListItem cards
   - For "prop": LibraryPropListItem cards
   - For "sound": SoundAssetListItem rows with category badge
5. Click card calls onSelect with {id, name, primary_ref_url} then closes modal
6. "Create New" link at bottom that opens the Asset Library in a new tab or navigates (stretch goal -- can be a simple text link to /asset-library)
7. Exclude already-bound assets by filtering out excludeIds from the list

Use the same styling patterns as existing modals in the codebase (dark theme, rounded borders, gray-800 backgrounds for cards).

**CastingSection.tsx** -- Shows cast bindings within a Production Bible and provides add/edit/remove.

Props:
```typescript
interface CastingSectionProps {
  bibleId: string;
}
```

Structure:
1. Header: "Cast" with "+ Add Cast Member" button
2. On mount, fetch cast bindings: `listCastBindings(bibleId)`
3. Grid/list of cast binding cards:
   - Actor thumbnail (from actor.primary_ref_url or placeholder)
   - Character name (bold), played by Actor name (muted)
   - Role badge (LEAD/SUPPORTING/EXTRA/NARRATOR)
   - Tag badge (e.g., KING_ALDRIC)
   - Edit button (opens inline edit form for character_name, role, tag, behavioral_notes)
   - Remove button (calls deleteCastBinding, refreshes list)
4. "+ Add Cast Member" opens AssetPicker with assetType="actor"
5. On asset selection from picker, show a "Cast as Character" form:
   - Character name (text input, defaults to actor name)
   - Role dropdown (LEAD/SUPPORTING/EXTRA/NARRATOR)
   - Tag input (auto-generated from character name: uppercase, underscores, e.g. "King Aldric" -> "KING_ALDRIC")
   - Optional: character_description, character_arc, behavioral_notes textareas
   - Save button calls createCastBinding(bibleId, { actor_id, tag, character_name, role, ... })
6. Exclude already-cast actor IDs when opening picker (prevent double-casting)
