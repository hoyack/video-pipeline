Create `frontend/src/components/codemirror/assetTagCompletion.ts` with two exported factory functions:

1. `createAssetTagCompletion(boundAssets: BoundAssetSummary[]): Extension` -- CodeMirror autocomplete extension:
   - Import `autocompletion`, `CompletionContext` from `@codemirror/autocomplete`
   - Import `Extension` from `@codemirror/state`
   - Import `BoundAssetSummary` as type from `../../api/types.ts`
   - Return `autocompletion({ override: [completionSource] })` with a single CompletionSource
   - In the source function: use `context.matchBefore(/@\w*/)` to detect @ prefix
   - If no match, return null. If match, return `{ from: match.from, options: [...] }`
   - Map each boundAsset to a Completion: `label: "@" + asset.tag.toLowerCase()`, `detail: asset.type + ": " + asset.name`, `info: asset.description ?? undefined`, `type: asset.type === "CHARACTER" ? "variable" : asset.type === "SET" ? "class" : "property"` (CodeMirror uses type for icon styling)
   - Set `activateOnTyping: true` so autocomplete triggers as user types

2. `createTagHoverPreview(boundAssets: BoundAssetSummary[], onTagSelect?: (tag: string | null) => void): Extension` -- CodeMirror hover tooltip:
   - Import `hoverTooltip` from `@codemirror/view`
   - Build a Map from tag (lowercase) to BoundAssetSummary for O(1) lookup
   - Return `hoverTooltip(callback, { hoverTime: 200 })`
   - In the callback: get the line at `pos`, extract text, find column offset, scan for `@([a-zA-Z0-9_]+)` matches using regex exec loop
   - When cursor column falls within a match range: look up the tag in the map
   - If found: call `onTagSelect?.(tag)` and return a Tooltip with `pos`, `end`, `above: true`, and a `create()` function that builds a DOM div with class `cm-tag-tooltip` containing `<strong>TYPE: Name</strong>` and optionally a one-line description (truncated to 80 chars)
   - If no match or not found: call `onTagSelect?.(null)` and return null

Add styles for `.cm-tag-tooltip` in `VidpipeEditorTheme.ts`:
- Add to the existing theme object: `".cm-tag-tooltip": { padding: "4px 8px", fontSize: "12px", lineHeight: "1.4", maxWidth: "300px" }` and `".cm-tag-tooltip strong": { color: "#93c5fd" }` (blue-300 for asset name)
