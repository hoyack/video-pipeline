Create `VoiceScriptService` with methods:

- `get_or_create_active_script(session, production_id)`
- `generate_from_screenplay(session, production_id, adapter, model_id)`
- `resolve_line_binding(session, line)`
- `resolve_all_bindings(session, voice_script_id)`
- `generate_line_audio(session, line_id, audio_adapter, api_key)`
- `generate_pending_audio(session, voice_script_id, api_key)`

Generation prompt rules:
- Input existing Screenplay fields plus Production Bible cast context.
- Ask for `line_type`, `speaker_tag`, `speaker_name`, `text`, `delivery_notes`, `timing_hint`, and `lip_sync_mode`.
- Explicitly forbid provider voice IDs in LLM output.

Binding resolution order:
1. Existing `cast_binding_id`
2. `speaker_tag` to `CastBinding.tag`
3. speaker name to `CastBinding.character_name`
4. unresolved warning/status, not crash

Voice profile resolution order:
1. `CastBinding.voice_profile_id`
2. first actor `ActorVoiceProfile`
3. matching legacy `VoiceProfile`
4. narrator/default fallback if available
5. `SKIPPED` with error message
  </action>

    - missing cast/voice conditions produce line warnings/status instead of uncaught exceptions
    - line audio generation stores `audio_path`, `duration_seconds` when available, and `generation_status`
  </done>
