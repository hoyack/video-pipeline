  <action>
Create `backend/vidpipe/api/asset_library.py` with `asset_library_router = APIRouter(tags=["asset-library"])`. Follow the same CRUD pattern as `characters.py` (Pydantic request models, _to_dict helpers, async_session context manager).

**Actor endpoints:**
- `GET /api/asset-library/actors` -- list with optional `?search=` query param (ILIKE on name). Return list of actors with ref counts and binding counts.
- `POST /api/asset-library/actors` -- create. Body: `{name, description?, base_appearance_prompt?, prompt_tags?}`. Return created actor.
- `GET /api/asset-library/actors/{id}` -- get with all sub-entities (refs, voice_profiles, wardrobe_presets). Also include `bindings` count (number of CastBindings).
- `PUT /api/asset-library/actors/{id}` -- update top-level fields.
- `DELETE /api/asset-library/actors/{id}` -- check for CastBindings first. Return 409 if bindings exist (with count). Otherwise delete actor + cascade sub-entities.
- `POST /api/asset-library/actors/{id}/refs` -- upload reference image (multipart). Save via storage backend pattern (see Research code example). Create ActorRef row.
- `DELETE /api/asset-library/actor-refs/{ref_id}` -- delete a reference image.
- `POST /api/asset-library/actors/{id}/voice-profiles` -- create ActorVoiceProfile. Body: `{voice_id?, adapter_type?, style_notes?, sample_url?}`.
- `PUT /api/asset-library/actor-voice-profiles/{id}` -- update voice profile.
- `DELETE /api/asset-library/actor-voice-profiles/{id}` -- delete voice profile.
- `POST /api/asset-library/actors/{id}/wardrobe-presets` -- create ActorWardrobePreset. Body: `{label, description?, reference_images?}`.
- `PUT /api/asset-library/actor-wardrobe-presets/{id}` -- update wardrobe preset.
- `DELETE /api/asset-library/actor-wardrobe-presets/{id}` -- delete wardrobe preset.

**LibrarySet endpoints:**
- `GET /api/asset-library/sets` -- list with optional `?search=`.
- `POST /api/asset-library/sets` -- create. Body: `{name, description?, reverse_prompt?, style_tags?, prompt_tags?, lighting_notes?}`.
- `GET /api/asset-library/sets/{id}` -- get with refs, sonic identity, binding count.
- `PUT /api/asset-library/sets/{id}` -- update.
- `DELETE /api/asset-library/sets/{id}` -- check SetBindings, 409 if bound.
- `POST /api/asset-library/sets/{id}/refs` -- upload reference image (multipart). Create LibrarySetRef.
- `DELETE /api/asset-library/set-refs/{ref_id}` -- delete ref.

**LibraryProp endpoints:**
- `GET /api/asset-library/props` -- list with optional `?search=`.
- `POST /api/asset-library/props` -- create. Body: `{name, description?, appearance_prompt?, prompt_tags?}`.
- `GET /api/asset-library/props/{id}` -- get with refs, binding count.
- `PUT /api/asset-library/props/{id}` -- update.
- `DELETE /api/asset-library/props/{id}` -- check PropBindings, 409 if bound.
- `POST /api/asset-library/props/{id}/refs` -- upload reference image. Create LibraryPropRef.
- `DELETE /api/asset-library/prop-refs/{ref_id}` -- delete ref.

**SoundAsset endpoints:**
- `GET /api/asset-library/sounds` -- list with optional `?search=` and `?category=` filter.
- `POST /api/asset-library/sounds` -- create. Body: `{name, category, subcategory?, description?, audio_url?, generation_prompt?, tags?}`.
- `GET /api/asset-library/sounds/{id}` -- get with binding count.
- `PUT /api/asset-library/sounds/{id}` -- update.
- `DELETE /api/asset-library/sounds/{id}` -- check SoundBindings, 409 if bound.
- `POST /api/asset-library/sounds/{id}/audio` -- upload audio file (multipart, 20MB limit). Update audio_url.
